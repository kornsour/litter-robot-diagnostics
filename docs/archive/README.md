# Archive

This folder holds documentation and records that are no longer current: superseded
plans, resolved investigations, retired designs, and anything else that describes a
past decision, plan, or state of the project rather than the present one.

Nothing here should be used to understand how the project currently works, what is
currently true about the hardware or software it describes, or how to approach new
work. Treat every file under this folder as historical context only — useful for
understanding *why* something happened or *how a past problem was reasoned through*,
but never as a source of current facts or current guidance.

Contributors and coding agents: do not use anything in `docs/archive/` to inform new
work, and do not treat it as reflecting the current state of the project. If a file
here conflicts with something in the top-level docs, the top-level docs win.
